# Setup
1. Create a public repo named exactly `Jeffrin-Singh` on GitHub.
2. Upload `README.md` and the `assets/` folder to the repo root.

Notes
- Your neon portrait is embedded (base64) inside `header.svg`, `dashboard.svg` and `connect.svg`, with a rotating neon ring, floating motion, scan line and a "face 0.98" detection box.
- `assets/avatar.jpg` is the cropped photo, if you need it elsewhere.
- Stats and percentages are plain text in the SVGs; edit them directly.
